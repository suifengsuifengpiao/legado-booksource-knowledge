# 站点档案：xs5200（5200小说网）

> 建档 2026-10-23，来源：用户提供书源 + 20 天实战档案。**搜索端点被 Cloudflare Turnstile 拦截，已判不可用；发现/详情/目录/正文真机验证通过。**

## 1. 站点概况

| 项 | 值 |
|---|---|
| 域名 | `https://www.xs5200.net`（另有 m 站 `m.xs5200.net`） |
| UA 策略 | **全局桌面 UA**（www + 移动 UA 会 302 跳 m 站；站点 JS 按屏幕宽度/触摸能力检测强制跳回 m 域，改 UA 无用） |
| 盾 | Cloudflare **Turnstile 交互质询**（仅搜索端点），验证态为站长自签 `wsii.sig` cookie，绑设备 TLS 指纹 + IP |
| 结论 | 搜索认盾，走 Bing 兜底；其余通道正常 |

## 2. 搜索端点考证（为何不可用）

- `searchUrl` 走隐藏 WebView 直连 m 站 `search.php?keyword=`：真机浏览器（鸿蒙 ArkWeb 内核）访问同一页面可免验证放行，但 Legado 隐藏 WebView 以浏览器身份 + 真实内核访问仍被质询（`; wv` 标记、缺 `window.chrome`，WebView 形态固有缺陷）；
- Cookie 移植方案已排除：真机 vConsole + Cookie Editor 双重查证，该站**不签发 cf_clearance**，验证态为 `wsii.sig`（绑设备 TLS 指纹/IP，跨设备移植无效）；
- 纯 JS（Rhino）无法过 Turnstile：三层死结详见《过盾专题_CF盾物种与Turnstile三层死结》；
- 收尾：`webWait` 设 ~10000 快速失败，`loginCheckJs` 检测质询页弹 toast 引导用户换兜底源（节流 60 秒，时间戳存源变量 `_shieldT`）。

## 3. 页面结构与规则要点

### 搜索页（m 站 search.php，备用）

- 列表：`ul.lis > li`
- 字段：`span.s1`=分类、`span.s2 > a`=书名链接、`span.s3`=作者
- `bookUrl` 需 `^/` 替换还原为桌面版书籍页（`##^/##https://www.xs5200.net/`）——**桌面版书籍页内嵌全量目录，移动版目录分页不全**

### 目录 / 详情 / 正文（真机验证通过）

| 规则 | 值 |
|---|---|
| `ruleToc.chapterList` | `//div[contains(@class,"listmain")]//dl/dt[contains(text(),"正文卷")]/following-sibling::dd/a` |
| `ruleBookInfo` | `div.info` 结构：`h2`=书名、`div.small > span` 序列取作者/分类/字数、`div.cover > img`=封面、`div.intro`=简介 |
| `ruleContent.content` | `@CSS:div#content@html` + `##` 清洗：app 推广、章节 URL 水印、域名记忆句 |

### 发现页

`@js:` 生成分类（玄幻/修真/都市/历史/网游/科幻/言情 `/xuanhuanxiaoshuo/{{page}}.html` 式）+ 全本 `/quanben/{{page}}.html` + 排行榜 `/paihangbang/`，flex 布局。

## 4. Bing 兜底方案

随附「5200小说网-Bing兜底.json」：`searchUrl` 写 `https://www.bing.com/search?q=site:xs5200.net+{{key}}`，从 Bing 结果页提取本站书籍链接。覆盖面往往比站内搜索还全。**这是 Turnstile 站的搜索标准解法。**

## 5. 教训

1. **先取证盾的物种再动手**： Turnstile 与五秒盾不是一个物种，拿五秒盾的解法（webWait 拉长）应对 Turnstile 只是让质询页晚点到；
2. **cf_clearance 不是默认选项**：有些站只签发站长自签 cookie（`wsii.sig`），移植前先在真机查证该站到底签什么；
3. **移动版目录分页不全**：从移动版搜索页进书要还原桌面版 URL，桌面版书籍页内嵌全量目录。
