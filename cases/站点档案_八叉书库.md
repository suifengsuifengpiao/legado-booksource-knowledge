## 二、正文形态：页面里只有「接口令牌」，正文要二次 POST

章节页 DOM 里没有正文，只有一个**行内 JSON 块**，含着调用接口所需的全部参数：

```json
{"url":"...","mobile":"1","isk":"0","novel":"...","chapter":"...","t":169...,"n":"...","sign":"..."}
```

书源要做的是：**从页面取这些字段 → POST 到 `conapi.php` → 解析返回 JSON 的 `content`**。

### 2.1 取字段：用锚点开窗，不要依赖字段顺序

```js
var hit = h.match(/"url"\s*:\s*"([^"]+)"/);
var blk = hit ? h.substring(hit.index, hit.index + 1600) : "";   // 以 "url" 为锚点向后开 1600 字符窗
var pickStr = function(name){ var m = blk.match(new RegExp('"'+name+'"\\s*:\\s*"([^"]*)"')); return m ? m[1] : ""; };
```

> 用固定窗口而不是解析整个 JSON：页面里除令牌块外还有别的 JSON，全量 parse 容易炸；锚点 + 窗口在字段顺序变动时仍然成立。

### 2.2 接口地址必须写死，不能用 `baseUrl` 拼

**坑**：真机上 `baseUrl` 是**当前章节页 URL**（`https://bcshuku.com/novel/xxx/chapter0.html`），拿它拼 `conapi.php` 会得到 `.../chapter0.html/conapi.php` → **404**。

**修法**：接口地址硬编码 `https://bcshuku.com/conapi.php`；`Referer` 用站点根，仅当 `baseUrl` 含 `/novel` 时才用它。

## 三、坑一：`Packages.java.*` 会替换全局 `java` 对象

**症状**：先用过 `Packages.java.*` 之后，再调 `java.log(...)` / `java.post(...)` 报 **"not a function"**。

**根因**：Rhino 里 `java` 是全局引用；一旦访问 `Packages.java.net.HttpURLConnection` 这类成员，某些情况下会把全局 `java` 重绑成 `JavaPackage`，之后 `java.xxx` 的方法调用全部失效。

**修法（书源里已落地）**：

```js
var J = java;                                  // 第一行就存住
var log = function(s){ try { J.log(s); } catch(e){} };
```

> 通用结论：**任何 `<js>` 里只要出现 `Packages.java.*`，就必须在文件开头把 `java` 存进局部变量**，后续全用它。

---

## 四、坑二：`ConstString cannot be cast to java.lang.String`

**症状**：把 Rhino 的 Map 作为参数传给 Java 方法（设置请求头）时，真机抛 `ConstString cannot be cast to java.lang.String`。

**根因**：Rhino 的 `ConsString` 不是 `java.lang.String`，跨语言边界时 Java 侧强转失败。

**修法**：**不走 Map**，把请求头逐个作为**方法参数**传入（参数位会被转成 `java.lang.String`）：

```js
var conn = new Packages.java.net.URL(API).openConnection();
conn.setRequestMethod("POST");
conn.setRequestProperty("Content-Type", "application/x-www-form-urlencoded");  // 逐个传参，不组 Map
```

书源里最终是「三条路依次尝试、任一成功即止、失败只记日志不抛」：① 自建 `HttpURLConnection`；② 兜底路径；③ DOM 兜底。这样单条路失效不会整章空。

## 五、三轮迭代过程（为什么最后是这个形态）

| 轮次 | 做法 | 真机结果 | 教训 |
|---|---|---|---|
| v1 | 直接按页面 DOM 取正文 | 空 | 正文不在 DOM 里，在接口 JSON |
| v2 | 提取令牌 + `java.post` | 部分章空 | `Packages.java.*` 污染了 `java`，`java.post` 失效 |
| v3 | `var J = java` + 自建连接 + 三路兜底 + 固定接口地址 | **通过** | 见 3/4 节 |

---

## 六、一句话结论

> 正文走独立接口的站，四件事必须同时做到：**令牌用锚点开窗取、接口地址写死、`java` 先存局部变量、请求头走方法参数不走 Map**。
