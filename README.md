- **技能自检 v1.15.8（2026-11-01 08:56，只改文档）**：修正 v1.15.7 新节里一处**归因错误**。原句「只改一半，`display_name` 检查会多出一条 ERROR，11 条形态全变 `E=2`」——实测那条多出来的 ERROR 是 **3b「SKILL.md version=X, _meta.json version=Y → 两处必须同步」**，它关于 `version` 字段、**与 `display_name` 无关**；按原句去查会盯着 `display_name` 找问题，而真正要先修的是两处 `version` 没同步。**四种组合的完整矩阵（引擎侧实跑）**：两处都对 → `E=0`；只改 `version` → 只 3b，`E=1`；只改 `display_name` → 只 3c，`E=1`；两处都改 → 3b + 3c，`E=2`。另注明 **3c 文案的 `version=` 取 `SKILL.md` frontmatter（代码 206/210 行）而非 `_meta.json`**，两者不同步时它在指一个 `_meta.json` 里不存在的值；改正文案属代码改动，本版未动 `self_audit.py`，留待下次碰代码一并改。\n- **技能自检 v1.15.7（2026-11-01 08:25，只改文档）**：把「护栏的验收标准」写进 SKILL.md。起因是 v1.15.3→v1.15.6 连修四轮，六组自检**每组对应一种失效模式**，但文档里从没写过为什么不能精简——v1.15.5 和 v1.15.6 加第五、第六组时，都是靠"临时想起来断言方向相反不能混"才独立成组，**没有文档可查**。四类划分：A 该叫（反例注入 / 畸形 meta，防漏报）／B 该闭嘴（正例 / 日期在前的正确名，防误报）／C 该认怂（两段式，防冒充：判不了必须说判不了）／D 该照镜子（真实基线，防"沙盒自洽、真实已坏"）。**A 与 B 方向相反、C 独立于二者，混进同一棵树会互相抵消。**\n- **技能自检 v1.15.6（2026-11-01 01:55，修反向误报）**：`display_name` 版本检查的 `v?` 让前缀可选，等价于「取展示名里第一个数字串」，`2026.11.01 v1.15.5` 因此取到日期当版本、对着正确版本号报 ERROR。改为两级匹配（带 `v/V` 前缀优先，无前缀才退回裸数字串）。**验收标准是双向的**：① 日期在前的**正确**展示名须放行（`exit=0` 且无「版本漂移」）；② 日期在前的**错误**展示名须照旧 `exit!=0` 且指向真版本号。只验 ① 会顺手把检查器改瞎——`--self-test` 第五组方向与前四组相反（要求 `exit==0`），必须独立成组，混在一起会互相抵消。\n- **技能自检 v1.15.5（2026-11-01 01:05，判不了就说判不了）**：`display_name` 版本检查的正则原为 `v?(\d+\.\d+\.\d+)`，两段式 `v1.15`、`1.15(beta)` 匹配不上 → 落进「无版本号 → 跳过」→ **静默放行且自检全绿**。这是「样本不合预期 → 静默 → 绿」的第四例（前三例：`display_name` 不同步、`_meta.json` 损坏、两段式）。修法：正则放宽到 `v?(\d+(?:\.\d+)+)`；**恰好三段**照旧比对、不一致报 ERROR；**段数≠3** 报 NOTE 非阻断；**完全无版本数字**才真正跳过。新增 `notices` 通道，`main()` 在 `[OK]` 之前打印 `[NOTE]`，**exit code 不变**——`[OK] 五项检查全部通过` 与 `[NOTE] 判不了` 必须能同时出现且不互相冒充。`--self-test` 增第四组反例「两段式 NOTE」，独立成组（断言 `exit=0` 且输出 `[NOTE]`，方向与前两组相反，混在一起会互相掩盖）。
- **技能自检 v1.15.4（2026-11-01 00:50，修护栏静默停摆）**：`_meta.json` 损坏（非法 JSON / 空文件）时，3b 与 3c 两段被 `except Exception: pass` 同时吞掉，**自检输出 `[OK] 五项检查全部通过`**——文件删干净了会报错、文件坏掉了却放行，同一道防线只堵了一半。修法：两处 `pass` 改报 ERROR（「存在但无法解析」），并用 `meta_unreadable` 标志避免同一故障报两条；新增第三组反例「畸形 meta」进 `--self-test`。**三组毒标本实测**：截断 JSON → 报错、空文件 → 报错、合法但缺 `version` → 不误报。
